01 gl-badge

Status badge with animated pulse dot. Variants: available, busy, default. Renders uppercase text with a pulsing indicator dot. Badge de estado con punto pulsante animado. Variantes: available, busy, default. Renderiza texto en mayúsculas con un indicador pulsante.

02 gl-skill-tag

Monospace skill tag with colored border per proficiency level. Levels: strong (#CC1500), learning (#7C3AED), familiar (white/15). Tag de habilidad monospace con borde coloreado por nivel. Niveles: strong (#CC1500), learning (#7C3AED), familiar (blanco/15).

03 gl-project-card

Project card with dark background, hover border accent and top line animation. Pass stack as a comma-separated string. Tarjeta de proyecto con fondo oscuro, borde accent en hover y animación de línea superior. Pasá stack como string separado por comas.

04 gl-contact-button

CTA button. Variants: primary (white bg → accent on hover), ghost (transparent, white/20 border → accent border on hover). Sharp edges, uppercase, spaced tracking. Botón CTA. Variantes: primary (bg blanco → accent en hover), ghost (transparente, borde white/20 → borde accent en hover). Bordes rectos, uppercase, tracking espaciado.

Usage Uso

<gl-contact-button href="https://github.com/giuliannadr" label="View GitHub" variant="ghost"></gl-contact-button>
