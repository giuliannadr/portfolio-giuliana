Design System

web components. any framework.

01 gl-badge

Status badge with animated pulse dot. Variants: available, busy, default. Renders uppercase text with a pulsing indicator dot.

Usage
<gl-badge label="Open to work" variant="available"></gl-badge>
<gl-badge label="In a project" variant="busy"></gl-badge>
<gl-badge label="Full Stack Dev" variant="default"></gl-badge>
02 gl-skill-tag

Monospace skill tag with colored border per proficiency level. Levels: strong (#CC1500), learning (#7C3AED), familiar (white/15).

Usage
<gl-skill-tag label="React 18"      level="strong"></gl-skill-tag>
<gl-skill-tag label="Lit Element 3" level="learning"></gl-skill-tag>
<gl-skill-tag label="Rust"          level="familiar"></gl-skill-tag>
03 gl-project-card

Project card with dark background, hover border accent and top line animation. Pass stack as a comma-separated string.

Usage
<gl-project-card
  title="Aura DJ System"
  description="Business management platform for a DJ agency."
  stack="Next.js 15, Turborepo, Supabase, Drizzle ORM"
  live-url="https://facuujuarez.vercel.app"
  github-url="https://github.com/giuliannadr/FacuuJuarez-Aura"
></gl-project-card>
04 gl-contact-button

CTA button. Variants: primary (white bg → accent on hover), ghost (transparent, white/20 border → accent border on hover). Sharp edges, uppercase, spaced tracking.

Usage
<gl-contact-button href="mailto:hi@example.com" label="Let's work together" variant="primary"></gl-contact-button>
<gl-contact-button href="https://github.com/giuliannadr" label="View GitHub" variant="ghost"></gl-contact-button>
